## ⚙️ Getting Started

### Prerequisites

```bash
Node.js 18+
npm 9+
Git 2.17+
```

### Installation

```bash
git clone https://github.com/<your-username>/<repository-name>.git
```

```bash
cd <repository-name>
```

```bash
npm install
```

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
